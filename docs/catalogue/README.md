# IDEA catalogue review

Important: image files are held on the authorized work computer and are NOT uploaded to GitHub just because a local path is in this report. Before publication, verify image reuse rights, image text/collages, provenance, brand/manufacturer identities, duplicate records, and availability of media on IDEA's hosting.
