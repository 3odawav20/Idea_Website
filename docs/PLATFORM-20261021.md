# IDEA native platform release — 21 October 2026

Target repository: `3odawav20/Idea_Website`. Production host: `https://livefree.support`.
The existing PHP/MySQL account, quotation and membership tables remain in place.
`database/mysql-platform.sql` is an additive, repeatable migration. No test records,
prices, inventory or merchant credentials are seeded into production.

## Implemented paths

- `/account`: editable profile; email verification; password-protected deletion request.
- `/account/addresses`: private saved addresses.
- `/account/notifications`: persistent notifications and read state.
- `/account/orders`, `/account/invoices`: owned orders, immutable invoice snapshots,
  payment and delivery state, cancellation/refund requests.
- `/business/verification`: business details, private document upload, review submission.
- `/admin/platform`: document review state machine, authorized sale variants, actual
  delivery rates, order fulfilment, tracking records, refund requests and audit log.
- `/admin/ai`: masked Gemini key entry; backend checks image-model access before saving
  the key outside the document root with permission 0600. No key is returned by an API.
- `/cart`, `/checkout`: authenticated customer cart, authoritative integer monetary
  totals, owned address, configured delivery, stock reservation and idempotent ordering.
- `/ai-room-visualizer`, `/ceramic-studio`: existing room/material workflow with a
  modern instrument-panel appearance, floor/walls/ceiling selection, real processing
  states, before/after comparison, image download and account-owned design history.

## Gemini room editing

`public/api/platform-ai.php` is the dedicated server-side job and image-editing script.
It sends the exact room first and exact selected swatch second to Gemini's image model.
The prompt protects furniture, architecture, lights, openings, composition and camera;
it specifies the target surface, physical tile dimensions, angle and grout color.
Unrelated output aspect ratios fail validation. Optional manual surface coordinates
composite the result inside the selected polygon while retaining the original outside.
Automatic edits rely on the model's surface interpretation; visual acceptance with a
real room is required before asserting room-preservation quality. Furniture inside a
manually selected polygon also requires visual review. No unrelated result is substituted.

Only `GEMINI_API_KEY` is needed to enable the preconfigured Gemini image adapter.
The default model is `gemini-3.1-flash-image`. Images and results are stored privately,
not in the public upload directory. Daily limits are controlled by the private
`ai_daily_user_limit` and `ai_daily_global_limit` settings. No human-assisted trial or
different AI provider is used by this integration.

## Documents

Raster documents are decoded and re-encoded; metadata is discarded. PDF uploads require
an antivirus command with a clean exit, reject active PDF constructs, and fail closed
when the scanner fails or warns that its database is stale. The cPanel release uses
private ClamAV definitions under `/home/lsenet5/idea-platform-private/clamav`.
Download authorization checks company ownership or administrator role. The old direct
company-approval endpoint is blocked; approval must pass document review transitions.

## Payment, delivery and email boundaries

Paymob uses Intention API + hosted checkout. A browser redirect cannot mark an order paid.
Callbacks require SHA-512 HMAC, matching amount/currency/integration and atomic processing;
duplicate callbacks cannot consume inventory twice. Late payments enter review rather
than overselling. Refund requests and provider execution are distinct from confirmed
settlement. Unknown provider outcomes remain visible for reconciliation.

Bosta booking requires real merchant credentials, pickup location, district/city IDs and
package facts. Its custom secret webhook header is checked; duplicate/out-of-order
tracking events do not regress the current state. Manual tracking is labelled as an
administrator record. No shipment is created by the test suite against a real carrier.

SMTP has a persistent transactional outbox with retry handling and a CLI worker:
`scripts/send-platform-mail.php`. The password-reset endpoint fails explicitly without
configured SMTP. Queue insertion is not described as recipient delivery. Install a
cron worker after entering the real SMTP credentials; actual recipient acceptance must
then be verified. Existing memberships manage access; recurring provider billing is
not activated by granting an access membership.
